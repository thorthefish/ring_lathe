# Ring Lathe

This project is a mini-lathe for sandign the insides of 3d printed rings.

I made this project because Ive needed a way tto sand rings much faster cause getting them up to 600 grit took forever. So when I remembered that I had motors thatt i wasnt using, I scrapped my old rc cars for any parts i might need, and started thinkin about how tto power somthing like this. I also have some GT2 belts left over from robotics season so I decided to use those instead of gearin it.
